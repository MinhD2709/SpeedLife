# UniPilot hackathon build

- **Data:** Zetaris serves the versioned USYD curriculum catalogue.
- **Build:** Meterless Scout Intent routes and guards academic requests using signed contracts.
- **Power:** Nightshift is the only live model provider; a Nemotron-backed lane explains validated plans.

The model never chooses units. Python checks prerequisites, prohibitions, offerings,
completion status and credit load first. Uploaded PDFs remain request-scoped and are
discarded after extracting unit codes, marks and statuses.
