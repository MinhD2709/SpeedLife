# UniPilot

USYD course planning grounded in the 2026 Bachelor of Advanced Computing,
Computational Data Science handbook.

UniPilot extracts a redacted transcript and progression report, asks the student
to confirm the parsed record, queries curriculum facts through Zetaris, routes the
request through Meterless Scout Intent, validates the plan deterministically, and
uses Meterless Nightshift/NVIDIA Nemotron to explain the result.

See [docs/SETUP.md](docs/SETUP.md) for local and live integration setup.
